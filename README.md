# Portfolio

A personal portfolio built with **Next.js** and **Tailwind CSS**, showcasing my projects and skills with a modern, animated design. This portfolio acts like an online demo, allowing visitors to explore projects with live links effortlessly.

## Features

- **Frontend & Design:** Next.js + Tailwind CSS for responsive and sleek UI  
- **Animations:** Framer Motion for smooth interactive animations  
- **Live Projects:** Two featured projects with clickable live links  
- **Interactive Elements:** Animated skills (progress bars) and project previews  
- **Contact Form:** Built with Next.js Server Actions and [Resend](https://resend.com/) for email handling
